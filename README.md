¿Quieres poner a prueba tu amistad con tus amigos?

Frenemy es la aplicación perfecta para evaluar vuestro nivel de amistad, poniéndote a ti y a tus amigos a prueba con distintos minijuegos, como juegos de cartas donde tendréis que torpedearos los unos a los otros para alcanzar la victoria, sin mostrar ningún tipo de piedad por tus, “amigos”... ¿Sobrevivirá vuestra amistad a nuestros juegos? ¿Seréis capaces de afrontar este desafío? ¿O tendréis que buscar nuevas amistades? Descubrirlo en Frenemy.
¿Qué usuarios tendrá Frenemy y a que se dedicarán?
Administrador

Podrá modificar, añadir o eliminar juegos a la lista de juegos disponibles, y gestionar los usuarios.
Host

Usuario normal, que creará la sala, seleccionará entre los juegos disponibles y gestiona el orden de juego y número de jugadores.
Jugador

Participa en los distintos juegos, uniéndose a un Host, y jugando con otros jugadores, pudiendo consultar su afinidad y resultados.

En el proyecto, actualmente existen cuatro usuarios de prueba a (admin), b, c y d (usuarios), todos con la contraseña aa
Al arrancar el proyecto, cargamos en la base de datos amistades preexistentes, para que a, b y c sean amigos, con puntuaciones de amistad, y clasificaciones de partidas (para no ver los datos del perfil vacíos)

Empleo de la IA:
En este proyecto hemos empleado principalmente chatgpt y copilot (algunos commit salen marcados con uso de copilot), para consultar dudas sobre como hacer funciones o sobre comportamientos no esperados en el programa, que no sabíamos resolver. Nos ha resultado muy útil sobre todo, para encontrar errores que no econtrabamos, y que habríamos tardado mucho en obtener.
También lo hemos empleado para ajuste de estilos css, para automatizar más la tarea.
